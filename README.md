# Food Delivery Frontend Project
Frontend study project for food delivery service, built with pure native web technologies.

## Technology Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Client-side routing with History API
- LocalStorage for data persistence

## Project Structure

index.html
css/
style.css
js/
api/
api.js
pages/
home.js
login.js
registration.js
cart.js
profile.js
orders.js
state/
store.js
utils/
router.js

## Main Features
1. User registration and login with form validation
2. Browse food menu
3. Add products to shopping cart
4. Modify quantity and remove items in cart
5. Create orders and view order list
6. User profile and logout function

## How to Run
1. Download all project files
2. Open `index.html` directly with modern web browser (Chrome, Edge, Firefox etc.)
3. All pages and functions can be used normally

## Notes
This project uses LocalStorage to simulate shopping cart and order data for demonstration.
